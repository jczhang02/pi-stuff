Claude Code UI 详细参考

本画廊来自已安装的官方 Claude Code 2.1.261, SHA256 为 4ae40dd1784e85753e742e09f267d29ecbb82890361ad3817d27560866d364a6. 每个 fixture 都在新的临时 project 中运行, 请求发送到 localhost Anthropic-compatible SSE fixture. Claude Code 真实执行了 Bash, Read 和 Edit call, fixture 只提供 model blocks.

阅读方式. Classic 是普通的紧凑 renderer. Fullscreen 会把已经完成的 tool activity 收起为数量 summary, Ctrl+O 打开详细 transcript. Compact 和 expanded 分别是同一次 Ctrl+O 操作前后的截图. running case 同时包含运行中和按下 Esc 后的画面. 这些是当前 client build 的证据, 不是 Claude Code 的通用契约.
