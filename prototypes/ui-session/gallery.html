Pi Stuff · 会话原型

以当前功能为范围, 在真实 Pi 中运行的新会话样式. 这里的图片来自可交互终端, 模型与执行数据是离线样例. 启动与操作说明 · 来源与详细规则 · 上一轮方案

  • Read/Grep/Find/Ls 连续成功两次起聚合. 点击组查看调用, 再点一项查看内容.
  • 工具采用“操作与目标 / 结果”两层. Write、Web 和成功 Bash 默认收起, Edit 保留三行短 diff.
  • WebSearch / WebFetch / WebRead 共用相同样式; 元数据只在展开后显示.
  • Thoughts 显示耗时, 点击阅读正文. 回答失败或中断保持普通文字.

欢迎页

保留 pi-stuff-old 的欢迎布局.

bun prototypes/ui-session/run.ts welcome

长 diff 与长路径

短预览注明隐藏行数; 展开恢复完整路径和带高亮的改动.

bun prototypes/ui-session/run.ts long-diff

完整会话

从定位到 Web 研究、修改和验证. 连续只读调用聚合, 工具默认收起.

bun prototypes/ui-session/run.ts session

定位问题

5 个连续只读调用聚合为两行; 点击组标题查看各次调用.

bun prototypes/ui-session/run.ts investigate

独立工具

Read、Grep、Find、Ls 默认只保留操作和结果两行.

bun prototypes/ui-session/run.ts tools

Web 家族

搜索、取网页、内容查找和续读共用相同层级, 技术元数据仅在展开时出现.

bun prototypes/ui-session/run.ts web

修改与验证

Edit 默认展示最多 3 行差异; Write 只报写入结果, 点击查看高亮代码.

bun prototypes/ui-session/run.ts changes

执行中

运行中的工具保留状态和两行最新输出, 完成后收起.

bun prototypes/ui-session/run.ts running

工具失败与空结果

工具失败保留原因, 没有匹配是正常结果. 不重复显示错误正文.

bun prototypes/ui-session/run.ts failures

长输出

UI 收起与上游截断分开表达, 输出路径一直可见.

bun prototypes/ui-session/run.ts long-output

思考过程

收起显示 Thoughts for 4s, 展开显示 Thoughts: 和正文.

bun prototypes/ui-session/run.ts thoughts

回答中断

已有回答仍保留, 中断是一行普通状态文字.

bun prototypes/ui-session/run.ts interrupted

回答失败

失败原因直接呈现, 无 Tool 标题、结果枝线或独立错误卡片.

bun prototypes/ui-session/run.ts response-error

无输出与取消

无输出、命令取消、图片文本回退都保留事实.

bun prototypes/ui-session/run.ts empty

动态执行

从思考到工具运行再到完成, 验证自动收起和 Esc 中断.

bun prototypes/ui-session/run.ts replay
