# Catppuccin themes

These Pi themes use the official Catppuccin Palette 1.8.0:
https://github.com/catppuccin/palette/blob/v1.8.0/palette.json

Each theme maps Pi's complete semantic color contract to one Catppuccin flavor. The three Tool background colors are
12% blends of the flavor's Mauve, Green, or Red over Base so Tool state remains readable without changing Pi's render
path. Pi owns theme selection, live switching, truecolor output, and its native 256-color fallback.

The palette is licensed under the adjacent `LICENSE` file.
