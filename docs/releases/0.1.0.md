# Pi Stuff 0.1.0 release candidate

> **Historical record.** This page describes the original `0.1.0` candidate at the time it was written. It is
> intentionally not a statement of the current Suite: later work adds Context, Web, MCP, and other capabilities,
> and the final acceptance report supersedes the capability and installation status below.

`0.1.0` is the first public release candidate for Pi Stuff. It is versioned and tested locally, but it is not published to npm yet.

## What ships

- One Aggregate Package, `@jczhang02/pi-stuff`, that loads the Suite through Pi's native Package system.
- A responsive Statusline, Welcome header, live Thought presentation, input enhancements, unified `/ui` settings, and one shared full-width non-floating Command Dialog.
- Compact, reload-stable presentation for Pi's built-in tools and Pi Stuff tools, with focused `/tools` details.
- Certified RTK 0.42.4 Bash rewriting with path/SHA drift protection, plus model-only Bash and Grep output projection that leaves stored Tool results exact.
- Codex Fast and usage controls plus selected patch and image Tools.
- A session-persistent Goal mode with settled-boundary continuation, automatic active reload recovery, explicit
  lifecycle controls, optional token budgets, a high non-disableable runaway backstop, and structured completion or
  three-distinct-attempt blocker evidence gates.
- Foreground and background Agents with bounded execution, a compact roster, durable current-session control, steering, cancellation, resume, and optional worktree isolation.
- Recoverable session Todo state and isolated one-shot BTW questions.

Each capability remains available as an independently installable Package. The Aggregate bundles the exact capability versions certified for this release.

## Installation

Before npm publication, install from a source checkout:

```bash
pi install ./packages/pi-stuff
```

After publication, the intended registry command is:

```bash
pi install npm:@jczhang02/pi-stuff
```

Pi owns installation and settings registration. Pi Stuff does not edit `settings.json` itself.

## Compatibility

The complete Suite is certified on Linux x64 against Pi source commit `bf4a90d81985bd45052eeeae59d84fe13e0bd2c8`, which reports version `0.83.0`. The tagged `v0.83.0` build is not compatible because it lacks the public Markdown transformation seam used by live Thoughts. Other Pi builds and operating systems are not claimed by this release.

See [Compatibility](../compatibility.md) for the complete Host and toolchain contract.

## Security boundary

Pi Extensions run with the user's operating-system permissions. This release intentionally adds no permission or command-interception layer. Review installed source and the [Security policy](../../SECURITY.md) before installation.

## Known limitations

- Adjacent Tool grouping is not shipped because the certified Pi Host has no public transcript-grouping seam. Each operation keeps its own compact row.
- BTW uses the active model and provider authentication through an isolated direct provider call. It cannot inherit the Host's complete provider lifecycle, retry, and transport path until Pi exposes a transcript-free side-call API.
- Long-horizon memory is not part of `0.1.0`; RTK only projects current Tool results for the model and does not replace session storage or compaction.
- Todo is Agent-managed in this release. Direct user add, cancel, and reorder controls remain future work.
- Plan/Ask, background shell monitoring, Loop/Cron, rewind, Web/MCP connections, `/doctor`, and default Skills are not included.
- No interactive browser is included by default.

## Provenance and support

Owned forks retain their MIT licenses, exact upstream revisions, archive identities, and local-delta records in each Package's `UPSTREAM.md`. The previous `jczhang02/pi-agent` repository was used only as behavior inventory and supplied no implementation code.

The supported line is `0.1.x`. Versions before `0.1.0` are unsupported workspace-development versions.
