# Pi Stuff 0.2.1 release candidate

> **Historical release candidate.** This page preserves the `0.2.1` installation and certification snapshot. It is
> superseded by later `0.3.x` work and does not describe the current Suite or certified Host.

`0.2.1` is the complete local daily-use candidate. It is versioned and certified for the maintainer's Pi installation,
but registry publication remains a separate explicitly approved action.

## What ships

- One ordered Aggregate Package with UI, Tools, RTK, Codex, Goal, Context, Web, MCP, Agents, Todo, and BTW.
- A conversation-first TUI: one compact footer, streaming Thoughts, compact reload-stable Tool rows, a task list above the
  editor, an Agent roster, and one shared full-width non-floating Command Dialog for settings and focused controls.
- Magic Context as an automatically activated, replaceable context engine. Pi JSONL remains the raw session authority;
  derived local state is project-isolated and failures fall back to Pi's native context.
- Certified RTK 0.42.4 rewriting and model-only output projection, without changing stored Tool results.
- `/codex` Fast and subscription-usage controls plus `apply_patch`, `view_image`, and `gpt-image-2` generation Tools.
- Persistent evidence-gated Goals, bounded Web search and public page/PDF reading, and a lazy stdio/HTTP MCP gateway.
- Foreground/background Agents, Agent-managed Todo, and transcript-isolated one-shot BTW questions.

## Installation and certification

The supported local path is a certified release artifact, not a source-worktree Package:

```bash
bun run release:pack -- .artifacts/release-0.2.1
bun run release:install-local -- .artifacts/release-0.2.1
```

The installer verifies the release manifest, archive hashes, and exact Pi Host provenance; extracts the Aggregate into an
immutable versioned directory under the Pi Settings Layer; preserves a settings backup; and keeps one stable Package
source. Repeating the command is idempotent.

## Compatibility

The complete Suite is certified on Linux x64 against Pi source commit
`bf4a90d81985bd45052eeeae59d84fe13e0bd2c8`, which reports `0.83.0`. The tagged `v0.83.0` binary is not compatible
because it lacks the public Markdown transformation seam used by streaming Thoughts. See
[Compatibility](../compatibility.md) for the full toolchain and Host contract.

## Deliberate boundaries

- Pi remains the Host; Pi core is not forked.
- There is no permission Capability, LSP, interactive browser, or default Skill bundle.
- Todo is Agent-managed; direct user editing is deferred.
- MCP uses one gateway Tool and does not expose MCP Apps or native/floating windows.
- Registry publication, a version tag, and a GitHub release require separate maintainer approval.

## Completion gate

This candidate is complete only after the versioned tree passes repository checks and release packing, the certified
artifact is installed into the real Pi Settings Layer, fresh and resumed real-model TUI sessions pass at wide and narrow
sizes, the final screenshot report is captured, remote CI is green, and `main` is clean.
