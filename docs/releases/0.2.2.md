# Pi Stuff 0.2.2 release candidate

> **Historical release candidate.** This page preserves the `0.2.2` installation and certification snapshot. It is
> superseded by later `0.3.x` work and does not describe the current Suite or certified Host.

`0.2.2` is the second installed-model dogfood candidate. It keeps the complete `0.2.1` Capability set and closes the
daily-use defects found while exercising that release in real Pi TUI sessions. Registry publication remains a separate,
explicitly approved maintainer action.

## Daily-use changes

- The Welcome header and `/codex` surface keep complete semantic units at narrow widths instead of producing clipped
  fragments.
- The ordinary Statusline contains only its accepted core fields; Goal and other Capability state no longer add rows.
- Successful `goal_complete` calls show one persisted, replayable completion summary below the shared Tool lifecycle row,
  while detailed evidence remains available through `/tools`.
- The shared Tool renderer no longer appends a settled result body twice during synchronous Host rendering.
- Small, self-contained Agent work stays in one Agent instead of creating wasteful nested delegation.
- Manual `/compact` under Magic Context produces a successful, source-marked managed-history boundary; an unhealthy Magic
  hook still fails open to Pi-native compaction.
- Explicit Magic Context recall synchronizes from Pi's authoritative JSONL and
  finds hidden early turns immediately after compact and cold resume without
  returning the still-visible live tail.

## Installation and certification

The supported local path is the certified release artifact, not a source-worktree Package:

```bash
bun run release:pack -- .artifacts/release-0.2.2
bun run release:install-local -- .artifacts/release-0.2.2
```

The installer verifies the release manifest, archive hashes, and exact Pi Host provenance; extracts the Aggregate into an
immutable versioned directory under the Pi Settings Layer; preserves a settings backup; and keeps one stable Package
source. Repeating the command is idempotent.

## Compatibility and boundaries

The complete Suite is certified on Linux x64 against Pi source commit
`bf4a90d81985bd45052eeeae59d84fe13e0bd2c8`, which reports `0.83.0`. Pi remains the Host and is not forked. There is no
permission Capability, LSP, interactive browser, or default Skill bundle. Pi JSONL remains session authority while Magic
Context owns replaceable derived context state.

## Completion gate

This candidate is complete only after the versioned tree passes all repository checks and release packing, the exact
artifact is installed into the real Pi Settings Layer, fresh and resumed real-model TUI sessions pass at wide and narrow
sizes, long-context and failure/degradation paths are exercised, the final screenshot report is captured, remote CI is
green, and `main` is clean.
