## Subsequent language-policy change

The bilingual GitHub task (`pi-stuff-ptn`) supersedes the former English-only public-prose policy quoted and described in row 18. That row records the quality-baseline migration and remains historical. The live [language and presentation policy](../../CONTRIBUTING.md#language-and-presentation) requires English first, Chinese second for new or substantively updated human-facing GitHub prose. Agent instructions and skills remain English-only; conversation remains Chinese. Chinese human-document counterparts now live under `docs/i18n/zh-CN/`.

## Added requirements

The root Code and tooling pointer reaches [engineering rules](engineering.md); the Deep review pointer reaches [PR evidence](pr-evidence.md#independent-review). These add the strict 15+1 anti-slop baseline, Oxlint correctness, no-bypass policy, pinned Effect v4 with the RC-only rejection prohibition, Oxfmt/GTS settings, behavior/regression preservation, and mandatory upstream structural review. [ADR 0002](../adr/0002-effect-quality.md) records the choice without replacing ADR 0001. Human-document counterparts link both ways; agent rules remain a single English source.

The document move used the original workflow text unchanged rather than paraphrasing its safety conditions. This audit records the implementation mapping; it is not evidence of independent review, successful checks, publication, or merge.
