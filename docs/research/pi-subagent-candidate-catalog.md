This appendix records discovery and source screening on 2026-09-12. Its 104 unique candidate names combine 30 prior/supplemental candidates and two groups of 37 directory entries. They represent 85 directory-visible names and 19 supplements. The directory header reported 87, while pagination produced 85 unique names; the discrepancy is retained. Sources are the [Pi package catalog](https://pi.dev/packages?name=subagents), versioned npm metadata and Git sources linked below.

This is a 104-entry screening inventory, not 104 equally deep code audits. Classifications describe the observed execution boundary; unverified capabilities are not treated as present. See the [decision report](pi-subagent-fork-decision.md) for the single fork recommendation, detailed comparisons, production LOC and unresolved boundaries. No candidate was installed or executed.

Downloads cover the complete UTC window 2026-08-12 through 2026-09-10 and do not count unique users. The three Git-only candidates have no applicable npm count; four unconfirmed zero values in group A are marked “unconfirmed.” npm metadata links pin the published version; Git-only links pin the reviewed source.
