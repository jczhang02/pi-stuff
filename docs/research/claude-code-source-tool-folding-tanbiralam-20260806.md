## Implementation trace

### Eligibility and classification

- Each Tool owns an optional `isSearchOrReadCommand` classifier. Native `Read` returns read; `Grep` and `Glob` return search ([`src/tools/FileReadTool/FileReadTool.ts:365-384`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/FileReadTool/FileReadTool.ts#L365-L384), [`src/tools/GrepTool/GrepTool.ts:175-194`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/GrepTool/GrepTool.ts#L175-L194), [`src/tools/GlobTool/GlobTool.ts:68-87`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/GlobTool/GlobTool.ts#L68-L87)).
- Bash is classified semantically. Explicit command sets map `find`/`grep`/`rg` and peers to search, `cat`/`head`/`wc`/`jq` and peers to read, and `ls`/`tree`/`du` to list. Parsing failure or any non-neutral command in a compound pipeline makes the whole command ineligible; neutral separators such as `echo` do not change an otherwise retrieval-only classification. Redirection operators and their targets are skipped, however, so redirection does not itself veto a retrieval classification; this is materially less conservative than Pi Stuff's AST plus side-effect checks ([`src/tools/BashTool/BashTool.tsx:58-91`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/BashTool/BashTool.tsx#L58-L91), [`src/tools/BashTool/BashTool.tsx:93-179`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/BashTool/BashTool.tsx#L93-L179), [`src/tools/BashTool/BashTool.tsx:469-477`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/BashTool/BashTool.tsx#L469-L477)).
- MCP folding is conservative and name-based: the mirror normalizes camel/kebab case and checks explicit search/read allowlists containing 489 unique names; unknown names remain standalone. Dynamically constructed MCP Tools carry server metadata and delegate to that classifier ([`src/tools/MCPTool/classifyForCollapse.ts:1-10`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/MCPTool/classifyForCollapse.ts#L1-L10), [`src/tools/MCPTool/classifyForCollapse.ts:577-595`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/tools/MCPTool/classifyForCollapse.ts#L577-L595), [`src/services/mcp/client.ts:1762-1813`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/services/mcp/client.ts#L1762-L1813)). Eligible MCP calls are counted separately and rendered as `Querying/Queried <server>` rather than as files or patterns ([`src/utils/collapseReadSearch.ts:792-818`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L792-L818), [`src/components/messages/CollapsedReadSearchContent.tsx:403-422`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L403-L422)).
- `WebSearch` and `WebFetch` do not implement the optional classifier in this snapshot, so despite their names they remain standalone in the ordinary retrieval group. `ToolSearch` and `Snip` are instead absorbed silently, while auto-managed Memory work has dedicated read/search/write counters; these are display-specific exceptions rather than general search verbs ([`src/utils/collapseReadSearch.ts:143-238`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L143-L238), [`src/utils/collapseReadSearch.ts:384-429`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L384-L429)).
- In the ordinary external path, non-retrieval Bash is a breaker. A separate fullscreen/no-flicker branch can absorb **all** Bash calls into a `Ran N bash commands` category; the environment helper says external users default off unless explicitly opted in, so that branch must not be mistaken for the default rule ([`src/utils/collapseReadSearch.ts:217-238`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L217-L238), [`src/utils/fullscreen.ts:127-146`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/fullscreen.ts#L127-L146)).

### Accumulator, boundaries, and counts

- The accumulator keeps original messages, Tool-use IDs, semantic counters, a `Set` of read paths, MCP server names, and the latest display hint. Flushing requires only a non-empty group, so **one eligible operation is enough**; there is no two-call threshold ([`src/utils/collapseReadSearch.ts:582-625`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L582-L625), [`src/utils/collapseReadSearch.ts:766-785`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L766-L785)).
- Eligible Tool uses and matching Tool results are appended to the current group. The scan never compares assistant message IDs, and matching `tool_result` user messages do not flush it; consequently retrieval can continue across consecutive assistant API messages in the same user turn ([`src/utils/collapseReadSearch.ts:786-897`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L786-L897)).
- Hard boundaries are non-empty assistant prose, a non-collapsible Tool use, or any other unrecognized/user message (including the next actual user prompt). Thinking/redacted-thinking, ordinary attachments, and system messages do not break a group; they are deferred, while selected hook and memory records are absorbed ([`src/utils/collapseReadSearch.ts:322-424`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L322-L424), [`src/utils/collapseReadSearch.ts:898-947`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L898-L947)).
- Native reads count unique path strings. Search, list, and MCP totals count operations; MCP server labels are deduplicated. Bash-only reads fall back to operation count, but once any path-based read exists the summary uses the path `Set` and intentionally does not add Bash read operations, avoiding likely double-counts at the cost of possible mixed-case undercounting ([`src/utils/collapseReadSearch.ts:675-753`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L675-L753), [`src/utils/collapseReadSearch.ts:819-884`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L819-L884)).

### Running, settled, hints, and errors

- A group is active while any member is in progress, or while the query is still loading and no real later content exists. The look-ahead ignores thinking, matching Tool results, eligible Tool uses, system messages, and attachments; this is what keeps one row live between assistant Tool rounds ([`src/components/MessageRow.tsx:40-93`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/MessageRow.tsx#L40-L93), [`src/components/MessageRow.tsx:114-127`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/MessageRow.tsx#L114-L127)).
- Active rows use present tense, a live marker and ellipsis; settled rows use past tense and dim treatment. Counts are held at their maximum observed value to avoid transient decreases during streaming ([`src/components/messages/CollapsedReadSearchContent.tsx:165-184`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L165-L184), [`src/components/messages/CollapsedReadSearchContent.tsx:342-410`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L342-L410), [`src/components/messages/CollapsedReadSearchContent.tsx:457-483`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L457-L483)).
- The accumulator replaces `latestDisplayHint` as operations arrive. Only an active row renders that hint; the hook holds the displayed value for at least **700 ms**, suppressing rapid target flicker. Settled rows omit the target line ([`src/utils/collapseReadSearch.ts:792-884`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L792-L884), [`src/components/messages/CollapsedReadSearchContent.tsx:24-26`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L24-L26), [`src/components/messages/CollapsedReadSearchContent.tsx:183-204`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L183-L204), [`src/hooks/useMinDisplayTime.ts:3-31`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/hooks/useMinDisplayTime.ts#L3-L31)).
- Error results do **not** veto folding: result membership is tested only by Tool-use ID, while counts are accrued from Tool uses before results arrive. The renderer notices an error for the active loader, but a settled compact row still uses the ordinary summary; verbose mode restores a per-call error marker ([`src/utils/collapseReadSearch.ts:428-445`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L428-L445), [`src/utils/collapseReadSearch.ts:888-897`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L888-L897), [`src/components/messages/CollapsedReadSearchContent.tsx:46-111`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L46-L111), [`src/components/messages/CollapsedReadSearchContent.tsx:161-164`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L161-L164)).

## Expansion, persistence, and Focus-view separation

`Ctrl+O` changes the entire screen between prompt and transcript; it is not a local disclosure on one folded row. Entering transcript freezes the current message/stream lengths, and that global transcript renders `Messages` with `verbose={true}`; the folded component's verbose branch iterates the retained original Tool uses individually ([`src/hooks/useGlobalKeybindings.tsx:90-132`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/hooks/useGlobalKeybindings.tsx#L90-L132), [`src/screens/REPL.tsx:4183-4197`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/screens/REPL.tsx#L4183-L4197), [`src/screens/REPL.tsx:4379-4404`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/screens/REPL.tsx#L4379-L4404), [`src/components/messages/CollapsedReadSearchContent.tsx:204-239`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/messages/CollapsedReadSearchContent.tsx#L204-L239)).

Folding is a display projection, not the persisted record. `Messages` normalizes stored messages and runs grouping/collapse inside a render `useMemo`; each synthetic collapsed object retains its original messages. Session-storage code likewise describes raw Tool uses/results as records that are *displayed* through collapsed groups, rather than storing the summary as the conversation ([`src/components/Messages.tsx:486-522`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/Messages.tsx#L486-L522), [`src/utils/collapseReadSearch.ts:675-753`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/collapseReadSearch.ts#L675-L753), [`src/utils/sessionStorage.ts:2393-2469`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/utils/sessionStorage.ts#L2393-L2469)).

The snapshot's separate quiet projection is named **Brief**, not Focus: the transcript toggle explicitly says Brief has its own toggle, while the render pipeline applies the Brief-only filter outside transcript and only afterward runs ordinary Tool collapse. This demonstrates mechanism separation, but the mirror does not establish exact parity between this gated Brief implementation and the current product's `/focus` command ([`src/hooks/useGlobalKeybindings.tsx:90-105`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/hooks/useGlobalKeybindings.tsx#L90-L105), [`src/hooks/useGlobalKeybindings.tsx:134-185`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/hooks/useGlobalKeybindings.tsx#L134-L185), [`src/components/Messages.tsx:477-522`](https://github.com/tanbiralam/claude-code/blob/6f6f12b37f529488b10e53928dd5508bb93535c7/src/components/Messages.tsx#L477-L522)).

## Bottom line

At this commit, default Tool folding is an aggressive, minimum-one, semantic retrieval accumulator. It spans assistant API-message boundaries, ends on prose or consequential work, shows a throttled latest target only while active, keeps failures folded, and relies on a global detailed transcript for recovery. The implementation is useful corroboration for Pi Stuff's behavioral research, but its unofficial, stubbed, version-ambiguous provenance means it should not be treated as authoritative Anthropic source or copied as a compatibility contract.
