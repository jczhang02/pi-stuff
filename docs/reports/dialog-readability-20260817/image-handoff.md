# Dialog readability report image handoff

Shared style anchor: light editorial terminal UI on warm parchment `#f5f4ed`, near-black text, warm gray separators,
one restrained ink-blue accent, full-width non-floating surfaces, monospaced UI copy, compact `◆` section marks, no
gradients, shadows, glass, dark mode, cards, decorative frames, or extra hues. These one-time deterministic layout
illustrations were rendered from SVG sources, not captured from a personal terminal theme. They are not maintained
product resources; Git history is their archive.
