# Pi Stuff 0.2.1 发布候选版

> **历史发布候选版。** 本页保留 `0.2.1` 的安装与验证快照。它已被后来的 `0.3.x` 工作取代，不描述当前套件或已验证宿主。

`0.2.1` 是完整的本地日用候选版。它已进行版本控制并针对维护者的 Pi 安装完成验证，但注册表发布仍是另一项必须显式批准的操作。

## 交付内容

- 一个有序聚合软件包，包含 UI、Tools、RTK、Codex、Goal、Context、Web、MCP、Agents、Todo 和 BTW。
- 对话优先 TUI：一个紧凑页脚、流式 Thought、紧凑且重载稳定的工具行、编辑器上方的任务列表、Agent 名册，以及一个共享全宽非浮动命令对话框，用于设置和聚焦控制。
- Magic Context 作为自动激活、可替换的上下文引擎。Pi JSONL 仍是原始会话权威；派生本地状态按项目隔离，失败时回退到 Pi 原生上下文。
- 已验证的 RTK 0.42.4 重写与只面向模型的输出投影，不改变存储的工具结果。
- `/codex` Fast 和订阅用量控制，以及 `apply_patch`、`view_image` 和 `gpt-image-2` 生成工具。
- 持久、证据门控的 Goal，有界 Web 搜索和公开网页/PDF 读取，以及延迟加载的 stdio/HTTP MCP 网关。
- 前台/后台 Agent、Agent 管理的 Todo，以及对话记录隔离的一次性 BTW 问题。

## 安装与验证

受支持的本地路径是已验证发布产物，而不是源码工作树软件包：

```bash
bun run release:pack -- .artifacts/release-0.2.1
bun run release:install-local -- .artifacts/release-0.2.1
```

安装器会验证发布清单、归档哈希和精确 Pi 宿主来源；把聚合包提取到 Pi 设置层下不可变的版本目录；保留设置备份；并只保留一个稳定软件包来源。重复执行命令具有幂等性。

## 兼容性

完整套件在 Linux x64 上，针对 Pi 源码提交 `bf4a90d81985bd45052eeeae59d84fe13e0bd2c8` 完成验证；该提交报告 `0.83.0`。带标签的 `v0.83.0` 二进制文件不兼容，因为它缺少流式 Thought 所需的公开 Markdown 转换接缝。完整工具链和宿主约定见[兼容性](../compatibility.md)。

## 有意保留的边界

- Pi 仍是宿主；不分叉 Pi 核心。
- 不包含权限能力、LSP、交互式浏览器或默认 Skill 集合。
- Todo 由 Agent 管理；用户直接编辑留待以后。
- MCP 使用一个网关工具，不暴露 MCP Apps 或原生/浮动窗口。
- 注册表发布、版本标签和 GitHub Release 需要维护者另行批准。

## 完成门槛

只有版本化树通过仓库检查和发布打包、已验证产物安装到真实 Pi 设置层、全新和恢复的真实模型 TUI 会话在宽窄尺寸下都通过、完成最终截图报告、远程 CI 为绿色且 `main` 干净时，该候选版才算完成。
