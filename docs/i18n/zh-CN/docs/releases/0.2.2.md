# Pi Stuff 0.2.2 发布候选版

> **历史发布候选版。** 本页保留 `0.2.2` 的安装与验证快照。它已被后来的 `0.3.x` 工作取代，不描述当前套件或已验证宿主。

`0.2.2` 是第二个已安装模型试用候选版。它保留完整 `0.2.1` 能力集合，并修复在真实 Pi TUI 会话中使用该版本时发现的日用缺陷。注册表发布仍是另一项必须由维护者显式批准的操作。

## 日用变更

- 欢迎标题和 `/codex` 界面在窄宽度下保留完整语义单元，不再产生被截断的碎片。
- 普通状态栏只包含其已接受的核心字段；Goal 和其他能力状态不再增加行。
- 成功的 `goal_complete` 调用在共享工具生命周期行下显示一条持久、可重放的完成摘要；详细证据仍可通过 `/tools` 查看。
- 共享工具渲染器不再在同步宿主渲染期间重复追加已稳定结果正文。
- 小型、自包含的 Agent 工作留在一个 Agent 中，不再制造浪费性的嵌套委派。
- Magic Context 下手动 `/compact` 会产生成功且标记来源的受管历史边界；不健康的 Magic Hook 仍开放回退到 Pi 原生压缩。
- 显式 Magic Context 召回会从 Pi 的权威 JSONL 同步，并在压缩与冷恢复后立即找到隐藏的早期轮次，同时不返回仍可见的实时尾部。

## 安装与验证

受支持的本地路径是已验证发布产物，而不是源码工作树软件包：

```bash
bun run release:pack -- .artifacts/release-0.2.2
bun run release:install-local -- .artifacts/release-0.2.2
```

安装器会验证发布清单、归档哈希和精确 Pi 宿主来源；把聚合包提取到 Pi 设置层下不可变的版本目录；保留设置备份；并只保留一个稳定软件包来源。重复执行命令具有幂等性。

## 兼容性与边界

完整套件在 Linux x64 上，针对 Pi 源码提交 `bf4a90d81985bd45052eeeae59d84fe13e0bd2c8` 完成验证；该提交报告 `0.83.0`。Pi 仍是宿主且不做分叉。不包含权限能力、LSP、交互式浏览器或默认 Skill 集合。Pi JSONL 仍是会话权威，Magic Context 负责可替换的派生上下文状态。

## 完成门槛

只有版本化树通过全部仓库检查和发布打包、精确产物安装到真实 Pi 设置层、全新和恢复的真实模型 TUI 会话在宽窄尺寸下都通过、长上下文与失败/降级路径均已演练、完成最终截图报告、远程 CI 为绿色且 `main` 干净时，该候选版才算完成。
