# Pi Stuff 0.1.0 发布候选版

> **历史记录。** 本页描述编写时的原始 `0.1.0` 候选版，有意不代表当前套件：后续工作加入了 Context、Web、MCP 和其他能力，最终验收报告也已取代下文的能力与安装状态。

`0.1.0` 是 Pi Stuff 的第一个公开发布候选版。它已在本地进行版本控制和测试，但尚未发布到 npm。

## 交付内容

- 一个聚合软件包 `@jczhang02/pi-stuff`，通过 Pi 原生软件包系统加载套件。
- 响应式状态栏、欢迎标题、实时 Thought 呈现、输入增强、统一 `/ui` 设置，以及一个共享全宽非浮动命令对话框。
- Pi 内置工具和 Pi Stuff 工具的紧凑、重载稳定呈现，并提供聚焦的 `/tools` 详情。
- 已验证的 RTK 0.42.4 Bash 重写，具备路径/SHA 漂移保护；另有只面向模型的 Bash 和 Grep 输出投影，并保持存储的工具结果完全不变。
- Codex Fast 和用量控制，以及选定的补丁与图像工具。
- 会话持久 Goal 模式：在稳定边界继续、自动恢复活跃重载、显式生命周期控制、可选 token 预算、不可禁用的高位失控后备限制，以及结构化完成或三次不同尝试的阻塞证据门槛。
- 前台和后台 Agent：有界执行、紧凑名册、持久当前会话控制、引导、取消、恢复和可选工作树隔离。
- 可恢复的会话 Todo 状态和隔离的一次性 BTW 问题。

每项能力仍可作为独立软件包安装。聚合包捆绑本次发布已验证的精确能力版本。

## 安装

npm 发布前，从源码检出安装：

```bash
pi install ./packages/pi-stuff
```

发布后，计划使用的注册表命令为：

```bash
pi install npm:@jczhang02/pi-stuff
```

Pi 负责安装和设置注册。Pi Stuff 不自行编辑 `settings.json`。

## 兼容性

完整套件在 Linux x64 上，针对 Pi 源码提交 `bf4a90d81985bd45052eeeae59d84fe13e0bd2c8` 完成验证；该提交报告版本 `0.83.0`。带标签的 `v0.83.0` 构建不兼容，因为它缺少实时 Thought 所需的公开 Markdown 转换接缝。此版本不对其他 Pi 构建和操作系统作出承诺。

完整宿主和工具链约定见[兼容性](../compatibility.md)。

## 安全边界

Pi 扩展以用户操作系统权限运行。本版本有意不增加权限或命令拦截层。安装前请审查已安装源码和[安全政策](../../.github/SECURITY.md)。

## 已知限制

- 未交付相邻工具分组，因为已验证的 Pi 宿主没有公开对话记录分组接缝。每项操作保留自己的紧凑行。
- BTW 通过隔离的直接 Provider 调用使用活跃模型和 Provider 认证。Pi 暴露无对话记录的旁路调用 API 前，它无法继承宿主完整的 Provider 生命周期、重试和传输路径。
- 长期记忆不属于 `0.1.0`；RTK 只为模型投影当前工具结果，不能替代会话存储或压缩。
- 本版本的 Todo 由 Agent 管理。用户直接添加、取消和重排控制留待以后。
- 不包含 Plan/Ask、后台 Shell 监控、Loop/Cron、回退、Web/MCP 连接、`/doctor` 和默认 Skill。
- 默认不包含交互式浏览器。

## 来源与支持

自有分叉在各软件包 `UPSTREAM.md` 中保留 MIT 许可证、精确上游修订、归档身份和本地差异记录。此前的 `jczhang02/pi-agent` 仓库只用于行为盘点，没有提供实现代码。

受支持版本线为 `0.1.x`。`0.1.0` 之前的版本都是不受支持的工作区开发版本。
