# Capability Contract 目录

[English](../../../../docs/capability-contract-catalog.md)

本目录列出当前 Pi Stuff Suite 面向用户或 Host 的稳定、可观察承诺。每行对应一个持久 Contract ID，并汇总
其正常、失败、恢复、持久化和边界场景；私有函数与单项测试不单列为合同。负责该行为的 Capability Module
README 仍是局部合同权威。

状态分为 `pending`、`blocked`、`pass` 和 `fail`。`pending` 表示尚未针对当前认证 Host
配置完成验收。Conditional Capability Contract 的已配置成功场景若因缺少可选可执行文件、凭据、Provider
或 Service 而无法运行，应记为 `blocked`，不能记作通过或跳过。`pass`、`fail` 和 `blocked`
必须链接到有日期的验收报告。

“证据”列声明当前验收所需的最小证据集，本身不表示这些证据已经重新执行。保留的
[2026-08-30 研究](reports/ps-ps3-capability-contract-and-terminal-bench-observation-2026-08-30.md)属于 Pi
0.84.3 的历史证据，不能认证当前这些 `pending` 条目。

为使 144 项合同与英文权威可逐项审计，合同 ID、行为陈述、公开边界及证据链接保留英文；本镜像翻译导航、
列名、场景标签和状态语义。
