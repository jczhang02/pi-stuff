# 基于当前 Pi Stuff 功能的未来 UI

[English](../../../research/future-ui-2026-09-21.md)

交付目标是当前已有功能的新 UI. 上一轮原生目录完成了覆盖盘点, 但没有回答这些内容未来应该怎样显示. [主画廊](../../../../prototypes/ui-direction/gallery.html)现改为完整会话与逐类新样式, 原生截图移到独立[参考页](../../../../prototypes/ui-direction/current-reference.html).

## 范围与设计

产品基线仍为 `cd0f174`, 已安装 Pi 0.85.1, 本轮预览从 `c5813d9` 开始修订. 当前 Web/RTK 和 Pi 原生消息、工具输出决定内容范围. 这是离线 UI 提案, 尚未生产实现或采纳.

方案沿用旧欢迎页及用户 ``、assistant/tool `•`、结果 `⎿` 前缀. 工具标题显示操作与目标, 下一行说明结果. Read/Write/Edit 保留语法高亮, 检索结果分开呈现位置与内容. Web 突出查询、网址和可读结果, 同时保留内容标识与分页元数据. 工具在原位置展开. 不增加检查器、Todo、Agents、Goal、后台工作、BTW 或会话命名.

主体覆盖原生清单中的 37 个状态. 可选自定义消息、entry renderer 和条件公告只留在参考页. 已有诊断及 compaction/branch 摘要仍按会话消息覆盖, 不由此设计通知系统或会话管理. 保留旧欢迎页和三种 diff 对照. A/B/C 仍是候选, 没有预先确定生产方案.

## 证据边界

新 renderer 使用与原生目录相同的离线输入, 再用四个场景组成完整会话. 布局受真实 Pi 输入框和视口约束, 模型、费用和状态字段是样例. 结果字段可以调整视觉顺序, 但保留失败、截断和分页信息.

原型通过自定义消息和鼠标区域展示新外观及展开行为, 不代表生产 user/assistant 或工具 renderer 已替换. 真实 provider、流式事件顺序、图片协议和会话重放不在本次验收内. 工具图片只展示文本回退. 变更片段样例不等于通用词级 diff 算法.

此前的[覆盖研究及一手来源](conversation-coverage-2026-09-20.md)继续作为实现依据. 旧版提供视觉参考, 当前产品清单决定范围. 未来预览代码位于原型目录的 `future-scenes.ts`、`future-extension.ts`、`future-messages.ts` 和 `future-tools.ts`, 使用现有 runner 截图.

## 截图验证

最终截图生成 45 组 PNG/ANSI/文本: 37 个分类场景、5 个会话总览变体和 3 个 Read 交互状态. 每组均通过预期文本与配色检查. Read 鼠标收起/展开及 Ctrl+O 保留了输入草稿. 主画廊共 52 张图, 包含保留的欢迎页和 9 张 diff 对照. 这些结果验证离线原型, 不代表生产 provider 或流式执行已验收.
