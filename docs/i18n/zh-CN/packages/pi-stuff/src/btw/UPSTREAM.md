## Pi Stuff 差异

- 用共享非浮层命令对话框替换浮动层。
- 用调用时 Pi 有效且感知压缩的上下文，替换缓存的原始分支快照。
- 通过活跃模型已注册的 Provider 和模型注册表认证解析，在原位置流式显示回答文字。Pi 尚无公开的无对话记录宿主调用接缝，因此 BTW 调用不参与 Provider 生命周期/上下文钩子，也不继承宿主重试和传输设置；Pi 暴露该接缝后再采用。
- 把成功历史保存为会话负责、不可见的自定义条目。它绝不发送给模型，可跨恢复保留，并被新会话与分叉会话 ID 忽略。删除跨会话问题提示。
- 围绕 Claude 风格信息密度重建界面：`/btw` 问题、Pi 原生加载器、Markdown 回答、紧凑历史和上下文控制；删除重复标题和说明标签。
- 增加复制、清除、Space/Enter/Esc 关闭，以及空闲安全的 `f` 提升：把选定问题和回答作为正式轮次放入新会话。
- 保留已完成文字、图像、工具调用/结果和压缩上下文；从调用快照排除未完成的 Assistant 部分。
- 通过内部对话 UI 约定，增加草稿、页脚、工作行、套件框架、抢占、关闭和失败恢复。
- 删除后续对话、浮动窗口几何、状态/组件输出和 0.83 之前的旧版传输回退。
- 增加 Pi Stuff 单元、隔离、持久化/恢复、提升、软件包、真实宿主，以及 100x32/64x28 PTY 验收门槛。

源码只在 Pi Stuff 内维护，没有独立软件包或发布生命周期。
