# Statusline 实施决策

[English](../../statusline-spec.md) · 英文为准.

最终设计汇总, 等待维护者确认共同理解. 尚未开始正式实现.

## 已接受

- 沿用 `59589c467215ec7394b36c2f60cea27e522316ad` 的双行原型: 第一行左目录/ctx/hit、右 Git; 第二行左模型/思考强度. 其他状态字段放第二行右侧, 让位于必要的 Git 重排.
- 默认启用自定义 statusline. 全局 pi-stuff.json 使用 statusline.enabled, 默认 true, /reload 后生效; false 恢复原生 footer. 首版不新增命令、设置面板、项目覆盖或逐字段配置.
- 复用原生 Git 分支变化通知. 初始化、Pi 工具执行结束、切换会话及 /reload 时补充刷新完整 Git 快照. 不新增固定轮询或递归项目监听. Pi 闲置时, 外部普通文件修改可能延迟到下个触发点才反映在计数中. 不自动 fetch 远端.
- 不在 Git 仓库时隐藏 Git 字段. Git 查询失败或超时时仅保留可信身份, 显示弱色 `git ?`, 隐藏过期计数. 后续成功刷新自动恢复, 不反复通知.
- Git 覆盖分支或 detached HEAD 身份、暂存/修改/未跟踪/冲突文件数、领先/落后提交数, 以及 rebase/merge 等进行中的操作. 窄屏优先保留身份、操作和冲突信息, 可选 ctx 统计退让.
- ctx 百分比仍为已用 token / 模型窗口容量. 自动 compact 开启时, T = 窗口容量 - 当前模型生效的 reserveTokens: 低于 0.9T 使用强调色, 从 0.9T 起使用警示色, 从 T 起使用错误色. 自动 compact 关闭时, 从窗口容量的 80% 起警示、90% 起错误色. 百分比和已用进度条同色, 切换模型或生效配置变化后更新阈值.
- ctx 使用 Pi 原生用量. 未知时按实际容量显示 `ctx ?/272k`, 不显示进度条或警示色, 不替换为零或压缩前旧值.
- hit 表示当前会话分支最近一次有效模型响应的 cacheRead / (input + cacheRead + cacheWrite). 输入量已知但无缓存命中时显示 0%, 无有效统计时隐藏 hit.
- 第三方字段直接读取现有 setStatus 条目, 按 key 排序, 保留大小写和颜色, 在第二行右侧以 `·` 分隔. 窄屏从末尾整项隐藏, 不新增注册协议或逐字段配置.
- Pi 只有一个自定义 footer 插槽. 支持第三方状态字段, 不组合另一套完整 footer; 不反复抢占, 由用户选择一套. 关闭开关恢复原生 footer.
- 全面优先复用原生能力. 通过当前 Pi 版本的原生配置读取器获取持久化 compact 设置, 保留其全局/项目/默认值优先级及该版本支持的模型覆盖. /reload 和切换模型时重读. 不访问私有实时宿主对象, 不承诺 SDK 临时覆盖完全一致.
- 沿用原生配置默认值和错误处理. 无法可靠确定 compact 配置时不猜压力阈值, 已知 ctx 数值以中性色显示. 已知 T 非正表示已达到触发边界, 用量已知时使用错误色. 模型/窗口数据缺失保持未知, 不当作零.
- 保持双行、正常空格及圆点分隔, 原始值大小写和自定义标签小写. 可选字段整项隐藏, 在视口允许范围内优先完整目录/Git身份, 仅当身份本身放不下时截断.
- 不开发新的 goal 或账号用量 provider.

## 验证与实施边界

使用隔离配置和确定性 provider 数据验证支持的真实 Pi 宿主 0.85.1、0.86.1、0.87.1. 覆盖正常/detached/尚无提交分支、修改/冲突/进行中的 Git 操作、worktree、查询失败及恢复、外部分支变化. 检查 150/100/80/50 列、明暗主题、compact 后 ctx 未知、两种颜色阈值模式及边界、切换模型、分支/恢复会话的 hit 选择、原生 setStatus 更新/移除、reload 和恢复原生 footer. 确认异步 Git 查询不阻塞输入, 释放时清理资源.

运行适用仓库测试和检查, 完成独立全量 diff 标准/需求审查, 发布真实终端截图和运行证据. 原型样例仅为视觉参考, 不代表生产数据或验收. 除已同意的配置字段外, 本设计不引入新依赖、私有宿主补丁、Pi fork 或生产持久化格式. 合并及发布另行授权.
