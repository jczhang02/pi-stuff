## 后续语言政策变更

双语 GitHub 任务 `pi-stuff-ptn` 取代第 18 行引用及描述的旧公开文字仅英文政策. 该行记录质量基线迁移, 保持为历史. 现行[语言与呈现](../CONTRIBUTING.md#语言与呈现)要求新增或实质更新的面向人 GitHub 文字先英文后中文. 代理执行指令和技能仍仅英文, 对话仍中文. 中文人类阅读对照位于 `docs/i18n/zh-CN/`.

## 新增要求

根的代码与工具指针到达[工程规则](engineering.md), 深度审查指针到达 [PR 证据](pr-evidence.md#独立审查). 它们增加严格的 15+1 anti-slop 基线、Oxlint correctness、禁止绕过、固定 Effect v4 及不得仅因 RC 拒绝的要求、Oxfmt/GTS 设置、行为/回归保全和强制上游结构审查. [ADR 0002](../adr/0002-effect-quality.md) 记录该选择, 不替换 ADR 0001. 人类文档对照双向链接, 代理规则保持单一英文来源.

文档移动使用原始工作流文字, 未改写其安全条件. 此审计只记录实现映射, 不证明独立审查、检查成功、发布或合并已经发生.
