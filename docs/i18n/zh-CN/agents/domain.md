# 领域文档

[English](../../../agents/domain.md) · 以英文为执行依据, 本文仅供人阅读.

## 探索前阅读

本仓库使用单一上下文:

- 根 `CONTEXT.md` 定义领域术语和模型.
- `docs/adr/` 保存架构决策记录.

探索代码前, 如果存在 `CONTEXT.md`, 先阅读它, 再阅读与任务相关的 ADR.

这些文件不存在时, 直接继续, 不必特别说明. 不要仅因文件缺失而创建占位内容或建议补建. 领域建模流程会在术语或决策确定后创建它们.

## 使用术语表

在 Issue、设计方案、测试和代码讨论中命名领域概念时, 使用 `CONTEXT.md` 定义的术语. 如果缺少某个必需术语, 先重新判断它是否属于本项目, 再指出真正需要领域建模补齐的缺口.

## 明确指出决策冲突

方案与现有 ADR 冲突时, 指出对应 ADR, 解释为什么需要重新考虑该决定, 不要默默覆盖它.
