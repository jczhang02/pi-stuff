# Pi Stuff

[English](../../../CONTEXT.md) · 英文为准。

Pi Stuff 为维护者的开发流程扩展 Pi。

## 术语

**网页访问（Web access）**：
Pi Stuff 在 Pi 内搜索网页、读取公开页面文本并查阅已获取内容的能力。

**工具开关（Tool switch）**：
独立决定模型能否直接调用某个 Pi Stuff 工具的设置。它控制调用入口，不禁止所有对底层能力的内部使用。

**子代理 (Subagent)**:
具有独立身份和对话上下文的受委派代理, 多次交办之间保留该身份和上下文.

**子代理任务 (Subagent task)**:
向子代理交办的一次工作, 具有独立的执行记录和结果. 续聊是交给同一子代理的新任务.

**子代理任务基线 (Subagent task baseline)**:
子代理任务开始时的代码状态, 尚未包含该任务自身的修改.

**跳过的任务 (Skipped task)**:
因依赖失败而未启动即结束的子代理任务.

**正在取消的任务 (Cancelling task)**:
已经收到取消请求, 但尚未确认停止执行的子代理任务.

**已完成子代理任务 (Completed subagent task)**:
子代理已报告完成交办, 且全部下级均已结束的任务. 任务完成本身不代表已经通过主代理验收.
