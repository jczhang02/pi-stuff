准确性边界： Pi Stuff 可以用 Pi 0.83 的 focus-taking overlay 覆盖部分或全部现有画面；它不能让 Pi Host transcript 为面板重新排版。这里的“全屏”仅指覆盖终端 viewport，下面的 transcript 仍然存在并可能继续收到输出。快捷键打开可保留主草稿并恢复焦点；通过 slash command 打开则不能保留命令前的草稿。后台输出可能让返回后的 transcript 位置 发生变化。真实 TUI 还会按终端高度回退到全覆盖，并自行处理行数、滚动与 Esc。此处的 鼠标点击只用于 HTML 预览，不承诺真实终端的鼠标操作。Pi 0.83 overlay 仍是实验接口， 实现时需要锁定版本并做尺寸回归测试。Settings 仅管理 Pi Stuff，不代替 Pi 原生 `/settings`。
