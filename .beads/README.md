# Beads workspace

Beads is the canonical issue tracker for this repository. The embedded Dolt database is local-only; `.beads/issues.jsonl` is the tracked public export, and GitHub Issues is a push-only public mirror.

See [`docs/agents/issue-tracker.md`](../docs/agents/issue-tracker.md) for the operating contract. Do not store credentials, private paths, or sensitive planning data in Beads.
